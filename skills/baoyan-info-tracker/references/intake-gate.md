# 启动检查：先问基础信息

这个 skill 不能一上来就给泛泛建议。先用温柔、陪伴式语气判断是否具备执行条件。

## 可直接执行的最低条件

用户至少提供：

- 目标专业/方向；
- 目标年份或保研届次；
- 检索范围：目标学校、城市/地区、学校层次三者至少一个；
- 任务类型：单校查询、院校清单、个人申请追踪、每日/每周更新中的至少一种。

如果缺任意一项，第一轮回复只能收集信息。

## 第一轮回复模板

```markdown
我们先不用急着定学校，我会陪你把信息一点点理清楚。先回答下面 6 个基础问题就好，确认后我再去查官方来源，并把结果整理成可筛选表格：

1. 你是哪一届保研/目标年份？例如 2027 届、2026 年夏令营。
2. 目标专业/方向是什么？例如新闻传播学、新闻与传播专硕。
3. 想查单个学校，还是整理一批院校？如果是一批，偏好哪些城市/地区/学校层次？
4. 你更关注学硕、专硕，还是都看？学费/学制有没有限制？
5. 是否要记录个人申请进度？例如报名、入营、参营、offer、面试、九推确认。
6. 输出想要 Markdown 表格、Excel/CSV 文件，还是两者都要？是否需要我帮你设置每日/每周定时任务来检查新公告和截止提醒？
```

## 禁止行为

基础信息不足时，不要输出：

- 院校推荐；
- 排名或择校建议；
- 保研方法论；
- 空泛行动清单；
- 没有用户约束的模板表。

可以简短说明：收集这些信息是为了帮用户少走弯路，避免推荐片面，并确保后续表格字段可筛选、可追踪。

## 用户只给部分信息时

不要重复问已知信息。只问缺失项。

示例：用户说“我是新传专业，帮我查保研院校”，则只需问：

先说一句安定用户的话，例如：“你已经给了专业方向，这一步很有用；我再补几项关键信息，就可以开始查官方来源了。”

1. 你是哪一届保研/目标年份？
2. 想优先看哪些城市/地区或学校层次？
3. 学硕、专硕还是都看？学费/学制有没有限制？
4. 是否要记录个人申请进度并生成 Excel/CSV？
5. 是否需要设置每日/每周定时任务？如果需要，希望几点检查、用什么方式提醒？
