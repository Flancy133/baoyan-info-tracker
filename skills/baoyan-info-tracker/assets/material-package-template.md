## 提交前检查

- [ ] 材料名称与公告一致
- [ ] 文件格式符合要求
- [ ] 文件大小符合要求
- [ ] 签字/盖章/扫描件已处理
- [ ] 成绩单、排名证明、英语证明清晰可读
- [ ] 个人陈述/研究计划已按学校方向定制
- [ ] 文件命名符合报名系统要求
- [ ] 已保存提交截图或回执
